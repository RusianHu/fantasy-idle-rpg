# 技术验证-演示页

本目录收纳与正式游戏隔离、但直接调用生产代码的技术验证页面。用途是检查渲染、特效、交互或性能方案，不作为玩家入口，也不承载独立业务逻辑。

## 目录规范

- 每项验证使用独立子目录，名称采用英文小写短横线，如 `map-effects/`。
- HTML 入口使用明确功能名，如 `map-effects.html`，不使用 `index.html`。
- 专属 CSS、JS、验证记录与入口同目录，并使用同一名称前缀。
- 优先直接加载项目生产脚本与注册表；禁止复制一套脱离生产代码的模拟实现。
- 页面须同时支持 `file://` 直开与项目静态服务器路径。
- 新验证页与现有验证页平级添加，互不引用私有资源。
