# 开放探索 v3 生成器审计

入口：`exploration-v3.html?seed=20260727&region=grassland&lang=zh-CN`。本页只调用 `Game.terrain.generate/validate` 的纯生成接口，不创建世界循环或写入状态。

- 导航格显示硬阻挡与可行走区；距离场显示阻挡净宽。
- 宏观层显示中心、主干、环路与替代路径；内容层显示地标、资源、奇物、生态、威胁和守门精英。
- 区块层显示 512px 的 5×3 世界分块。
- JSON 报告包含本次布局版本、尝试/修复/回退、完整结构指标与稳定内容 ID。
- 「批量审计 32 种子」对当前区域的确定性种子连续执行生成与验证，并汇报失败数、平均与最慢耗时。

完整验收仍以 `tests/v1_13.test.js` 的八区 1,600 布局、5,000 拓扑模糊种子和黄金摘要为准。
