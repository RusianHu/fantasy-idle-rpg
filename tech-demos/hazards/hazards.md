# Hazard 特效技术验证

独立页面直接加载正式 `hazardProfile`、`systems/hazards.js`、`render/hazards.js` 与世界渲染链。它用于验证：

- 八区域现场实例的线索、揭示、预警、激活、命中、冷却与导航成本。
- 九类视觉符号在六个关键状态下的轮廓、色彩、方向性和降动态表现。
- 像素 JRPG 视觉约束：机关材质化、离散地砖警戒符、逐类爆发碎屑、像素战斗铭牌，避免连续 HUD 圆环与大块透明覆盖。
- 固定 50ms tick 下的预警与伤害窗口，及中英文表现文案。
- 生产布局中的 Hazard 锚点、宏观骨架和内容接近链路；对比机关隐蔽路径与逐个揭示后的策略重规划路径。
- 逐机关记录计划覆盖链、线索/揭示/触发交叉、绕行结果、互动接近持续判定，以及安全/均衡逃生和掠夺接受风险事件。
- 复用正式噬宝匣确定性判定，模拟两只真箱保护、15% 合资格概率、三阶 Actor 变体与胜利/撤退奖励事务。
- 通过正式 `Game.guardSites`/`Game.hazards` 组合验证显形守卫、天气侦测成功、未识破伏击和交互抢占；抢占场景必须先建立真实移动/交互目标，再确认两者被原子取消并提交守卫 Encounter。
- 桌面与窄屏布局、44px 触控目标和 Canvas 视口适配。

URL 参数：`seed`、`region`、`lang`。页面暴露 `window.HazardEffectsLab`，供浏览器测试读取目录、快照、事件、路径审计/噬宝匣报告并调用阶段控制。
