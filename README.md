# 幻境远征 · Fantasy Idle RPG

纯前端、可离线运行的 **2D 像素风挂机放置 RPG**（日式中世纪奇幻 / JRPG 风格）。
沉睡千年的魔王在露西亚大陆苏醒，瘴气蔓延八方——你是公会新晋的独行冒险者，从新手草原一路讨伐至魔王城。

## 运行方式

- **双击直开**：直接用浏览器打开 `index.html` 即可游玩（全部脚本按序 `<script>` 加载，无 ES Modules，file:// 协议可用）。
- **静态服务器**（可选）：`python -m http.server 8080` 后访问 `http://localhost:8080/`。
- **移动端优先**：设计基准 390×844 竖屏；桌面浏览器居中显示手机比例容器。
- 无任何构建步骤、无外部网络依赖（EasyStar.js 0.4.4 MIT 与 Fusion Pixel 字体均已本地固定）。

## 发布与缓存

- HTML 始终重新校验；CSS、JS、字体统一使用 `BUILD_ID` 查询版本并长期不可变缓存，避免手机端新旧资源混用。
- 发布前执行 `.\tools\set-build-id.ps1 -BuildId YYYYMMDD.N`，随后运行 `node tests\cache-version.test.js`。同一发布内 `index.html`、技术演示、`Game.BUILD_ID`、字体 URL 与 `version.json` 必须一致。
- 长开标签页每 5 分钟及 `pageshow` / 重新可见时以 `no-store` 检查 `version.json`；发现新版后显示中英文更新按钮，点击时先收束过场并保存，再重载页面。
- VPS 的项目专属 Nginx 规则位于 `deploy/nginx/fantasy-idle-rpg-cache.conf`。部署规则后必须先执行 `nginx -t`，通过后才能 reload。

## 目录结构（引擎与内容分离）

```

version.json          当前发布 BUILD_ID（线上 no-store）
css/style.css         像素 JRPG UI（FF/DQ 式双线边框面板）
assets/fonts/         Fusion Pixel 12px 中文像素字体（woff2）
assets/sprite-source/ 采集物与探索宝箱的生成式母版及运行时预览
assets/sprites/       可独立复用的透明运行时 PNG（exploration/ 按稳定 ID 拆分）
tech-demos/           技术验证演示页（支持区域/世界种子 URL 参数）
js/
  vendor/             EasyStar.js 0.4.4（MIT，本地固定）
  core/               utils / eventbus / registry / audio(占位) / assets(精灵工厂) / save / loop / update
  i18n/               i18n 核心 + zh-CN + en 语言包
  data/               纯内容配置：formulas(数值公式集中) / regions / monsters / items / affixes / skills / achievements
  sprites/            像素素材（字符网格+调色板；含 v3 资源/地标/奇物/生态/守门精英与 manifest）
  systems/            state / terrain_v3 / exploration / expedition / expedition_ai / nav / inventory / combat / world / trade / progression / transitions / ending / offline
  render/             renderer(镜头/视差/合成) / terrain / exploration(分块与迷雾) / particles / daynight / effects
  ui/                 hud / 六 Tab 面板 / trade(统一交易面板) / transitions(短过场层) / ending(结局层) / 弹窗
  main.js             启动引导
```

**探索素材维护**：更新透明母版后，在 `tools/build-exploration-sprites.py` 的 `SPECS` 中登记稳定 ID/格位/尺寸，并在 `GROUPS` 指定所属区域；运行 `python tools\build-exploration-sprites.py` 即可重建 18 张单图、来源清单和区域模块。`*.generated.js` 不直接手改，提交前用 `--check` 验证源图哈希与产物一致。

**扩展方式**：新增一个区域 = 在 `data/regions.js` 注册一条数据（+ 怪物注册 + 语言包 key + 可选精灵），引擎自动生成地图列表、刷怪、掉落与 UI，零引擎改动。所有内容引用一律走稳定字符串 ID；存档遇到已下线 ID 自动优雅降级（装备折算金币、区域回退）。

**交易扩展**：区域以 `tradeAreas[]` 声明地点、实体、半径、优先级与目录，商店条目以 `catalogs[]` 声明供应渠道；`Game.trade.registerDynamic(area,{ttl})` 可注入不入档的临时地点。当前八区营地提供 `camp-general` 与 `camp-exchange`。

**区域顺序**：新档用 `world.worldSeed` 确定性排列前 4 个区域，后 4 个区域固定；怪物强度、奖励与推荐等级按本档推进位置计算。顺序写入存档，旧档迁移不会重新洗牌。

## v1.7 高密度区域布局

- `world.worldSeed` 是只读 `uint32`，地图面板显示 8 位十六进制值并可复制；刷新、离线回归和导出/导入不改变布局。
- `Game.terrain.build(region, worldSeed, layoutVersion)` 依次生成关键地标、材质块、主题走廊、装饰/细节、16px 导航代价和低代价出生候选；区域注册对象只保存约束。
- 根种子拆成 `landmarks / terrain / decor / details` 四个子流，调整花草细节不会改变营地、Boss、道路、材质块或大型装饰。
- 地形与大型装饰只提供软代价，不设置不可通行格。雪/沙、水、瘴气、熔岩依次提高移动代价，EasyStar 求解失败时回退直线移动。
- `layoutVersion:2` 按区域密度配置生成 98–135 个装饰、10–14 个材质斑块和 2.0–2.4 倍地表细节；大型丛聚装饰部分沿主路线两侧布置，森林、矿坑和洞窟的实际移动镜头不再稀疏。
- 历史 `layoutVersion:1` 生成路径与固定快照保留；v6 存档升级 v7 时只变化一次到 v2，世界种子和区域顺序不变。密集装饰的软导航代价封顶 `2.8`。
- 八区 QA：`tech-demos/map-effects/map-effects.html?seed=1234ABCD&region=forest`。页面可改 QA 种子，正式游戏不可重掷。

## v1.9 地图过场与死亡重整

- 自动推进固定为 3 秒路线倒计时、0.45 秒传送收束、0.18 秒遮罩原子换图、0.85 秒营地抵达；「留在本区」与 Esc 只取消本次，不改自动推进设置。手动选图跳过倒计时，仍复用完整换景。
- 自动操控抵达后复战；手动操控或手动首次进入新区时留在营地，重访则保留换图前的战斗/休息状态。世界只在遮罩最深处重建一次。
- 死亡为倒下 0.65 秒、灵魂回收 0.8 秒、营地落地 0.45 秒、分段恢复 4.2 秒、复苏 0.75 秒。恢复段不可快进；关闭特效或减少动态效果时保留时长与信息，移除震屏、残影和密集粒子。
- `Game.transitions` 统一提供 `startRegion/startDeath/cancel/update/isActive/blocksWorld/cameraTarget/settleBeforeSave`；玩家可见换区统一走 `Game.prog.requestRegion(rid,{source})`，`gotoRegion` 仅供遮罩中点、启动和导入等原子操作。
- 新事件为 `region:travelStart`、`region:travelCancelled`、`region:arrived`、`player:reviveStart`、`player:revived`；`region:changed` 仍只在真实世界重建时触发一次。存档保持 v8。

## v1.10.1 营地交易域

- 商店入口仍位于背包，但购买能力取决于角色的实时世界坐标：只有进入当前地图的运行时营地安全半径才开放；换区、传送、死亡重整及旧地图状态下均拒绝交易。
- 域外页面说明限制并提供「返回当前营地」，域内显示当前补给处；浏览期间跨出边界会立即锁定商品，底层购买 API 同步二次校验。
- 交易地点与商品目录分离：`tradeAreas[]` 解析程序化地标，`catalogs[]` 过滤供应内容，为同地图多商人、区域限定兑换和未来 v1.11「以物换物」预留直接扩展面。

## v1.11 世界交互与统一交易

## 数值设计说明

**成长方案**：二选一中采用「升级自动成长」——挂机游戏应尽量减少强制打断。升级自动提升全属性、回满 HP 并 +1 技能点；自动技能与换装默认开启，玩家可关闭总开关或锁定单个装备槽，随时切回完整手动决策。

**自动评估**：使用无副作用角色预览统一计算期望输出、对当前评估区域 Boss 的生存时间与经验/金币/掉落收益，并按职业权重取对数综合。永久技能点以最高已解锁区域评估，装备以当前区域评估；智能换装至少提升 0.1% 才替换，同分保留当前装备。

**职业数值形状**（基础值与复利见 `data/classes.js`）：五职业按「DPS × 有效生命 ≈ 恒定功率预算」设计——战士(HP150/复利1.078)坦而稳、盗贼(SPD12.5/暴击12%)快而脆、法师(ATK17/复利1.075)远程爆发、牧师(治疗强化+吸血)续航、游侠(远程+寻宝)均衡；远程职业以更低生存换取接敌前 1~2 次白嫖攻击。离线估算乘以职业爆发系数（战1.20/贼1.30/法1.35/牧1.15/侠1.25）。

**升级曲线**：`expNeed(L) = 28·L·1.16^(L-1)`（指数）。速度/暴击全职业线性微增。

**伤害公式**：`dmg = atk² / (atk + def)`（平滑减伤，无硬墙），±10% 浮动；暴击默认 150% 可成长。攻击间隔 `1.7·10/(5+spd/2)` 秒，速度既加攻速也间接加 DPS。

**区域怪物匹配**：怪物按区域 tier 指数缩放 `≈2.05^(t-1)`，与「玩家等级复利 × 装备加成（约 35%~55% 战力）」的复合成长率对齐；每区预期停留约 8~10 级，形成「入区偏难 → 毕业碾压」的推图节奏。Boss 为普通怪的 HP×11 / ATK×2.0，首杀奖励魔晶石 `15+10·tier`。

**经济闭环**：金币（产出：击杀/出售/离线/素材委托；消耗：药水/装备箱）；魔晶石（产出：Boss 首杀/成就/分解传说/高阶采集小概率；消耗：史诗箱/永久强化/生命刻印）；素材只由采集与宝箱产出，经集中配方兑换消耗，不影响离线收益。

**离线收益**：v3 以已知巡回路线长度、交互时间、节点冷却和路线危险度闭式结算；只有少量已揭示情报而未登记资源时按低效率战斗折算，完全无情报时不产出。旧 v1/v2 仍使用 `kills = 时长 / (单怪击杀耗时 + 2.5s 位移开销) × 0.8`，均无离线时长上限。

**防护设计**：药水低于阈值自动使用（默认 30%，可调，8 秒冷却），同一阈值驱动回营按钮警示；无药水靠自然恢复不中断挂机；死亡零惩罚 + 连败 3 次自动回退；魔王城战败立即退回浮空遗迹并重新锁图。Boss 讨伐失败或主动撤离均保留一半进度，但只有实际战败触发魔王城失守；血量不足 60% 时 Boss 暂缓登场，避免「登场即团灭」循环。

**大数字**：全局格式化函数按语言分派（zh：万/亿/万亿；en：K/M/B/T），超过 1e16 转科学计数法。
