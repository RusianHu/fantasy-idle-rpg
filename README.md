# 幻境远征 · Fantasy Idle RPG

纯前端、可离线运行的 **2D 像素风挂机放置 RPG**（日式中世纪奇幻 / JRPG 风格）。
沉睡千年的魔王在露西亚大陆苏醒，瘴气蔓延八方——你是公会新晋的独行冒险者，从新手草原一路讨伐至魔王城。

## 运行方式

- **双击直开**：直接用浏览器打开 `index.html` 即可游玩（全部脚本按序 `<script>` 加载，无 ES Modules，file:// 协议可用）。
- **静态服务器**（可选）：`python -m http.server 8080` 后访问 `http://localhost:8080/`。
- **移动端优先**：设计基准 390×844 竖屏；桌面浏览器居中显示手机比例容器。
- 无任何构建步骤、无外部依赖、无网络请求（像素字体 Fusion Pixel 已本地内嵌，缺失时自动回退系统字体）。

| --- | --- |
| **开场体验** | 标题画面（星空篝火营地全景 + 五职业围坐）→ 序章打字机 → 全屏职业选择（大立绘动画预览、←/→ 或滑动浏览、六技能预览）→ 淡入世界；老玩家秒进不受打扰 |
| **职业系统** | DnD 风格五职业（战士/盗贼/法师/牧师/游侠），开局选择、永久生效；数值成长、攻击方式（近战/远程弹道）、技能组、精灵立绘、武器全面区分 |
| **环境视觉** | 程序化多阶树冠大树（摇曳）、草簇风场行波、烘焙花簇/色斑/裂纹/雪地反光、发光体光晕（水晶/烛火/魂灯…）、林间光柱、道具软阴影、暗角；全部可开关、视口剔除（实测满帧） |
| 挂机战斗 | 伪实时制：每个实体按速度决定的独立攻击间隔自动出手；技能按冷却自动释放（受冷却缩减影响）；闪避/吸血/护盾/持续伤害/临时增益全套机制 |
| 平面世界 | 伪俯视 2D 场景，角色自动游走 / 索敌 / 走位接敌（远程职业站位输出，怪物被锁定后主动近身）；镜头平滑跟随 + 战斗推近 / Boss 拉近 |
| **点触交互** | 挂机为主、点击为辅：点怪物=锁定优先目标（金圈）、点地面=移动指令（绿圈，抵达后恢复自动索敌）、点篝火=扎营/拔营 |

| 装备 | 武器/护甲/饰品 3 槽；5 档稀有度（灰绿蓝紫橙）；随机词条、装备对比、一键出售、传说分解魔晶石；武器按职业呈现（长剑/短匕/法杖/战锤/长弓） |

| 扎营休息 | 一键扎营：走到篝火旁坐下打盹（Zzz），HP 快速恢复并积累「休整」增益（战斗时 +15% 经验 / +10% 掉率） |
| 死亡重整 | 零惩罚：撤回营地坐姿重整 6 秒回满复战；同区连败 3 次自动回退上一区域（Boss 战失败不计入，仅撤场保留一半讨伐进度） |
| 离线收益 | 关闭页面再回来按公式结算（无时长上限），弹窗确认后入账；休息模式离线则回满 HP + 休整增益积满 |
| 统计成就 | 事件总线驱动的统计页（14 项计数器）+ 18 个累计型成就（奖励金币/魔晶石） |

## 职业一览（DnD 核心四职 + 游侠）

| 职业 | 定位 | 攻击方式 | 专属机制 |
| --- | --- | --- | --- |
| 战士 Fighter | 近战坦克 | 近战 | 战吼增益、战斗回血、高 HP/DEF |
| 盗贼 Rogue | 近战爆发 | 近战 | 高速高暴击、闪避、毒素持续伤害 |
| 法师 Wizard | 远程法术 | 远程（法弹） | 最高攻击、冷却缩减、奥术护盾 |
| 牧师 Cleric | 近战续航 | 近战 | 治疗强化（含药水）、吸血、打击回血 |
| 游侠 Ranger | 远程物理 | 远程（箭矢） | 鹰眼增益、寻宝（金币/掉率加成） |

职业选定后**不可更改**（DnD 建卡传统）；换职业 = 重置存档。v1.0 旧存档载入时会提示补选职业，
旧技能点全额退还（等价一次免费洗点）。设计细节见 `PLAN/multiclass-plan.md`。

## 目录结构（引擎与内容分离）

```
index.html            入口（按序加载脚本）
css/style.css         像素 JRPG UI（FF/DQ 式双线边框面板）
assets/fonts/         Fusion Pixel 12px 中文像素字体（woff2）
js/
  core/               utils / eventbus / registry / audio(占位) / assets(精灵工厂) / save / loop
  i18n/               i18n 核心 + zh-CN + en 语言包
  data/               纯内容配置：formulas(数值公式集中) / regions / monsters / items / affixes / skills / achievements
  sprites/            像素素材（字符网格+调色板，运行时编译为 canvas，自动描边/镜像/呼吸帧）
  systems/            state / inventory / combat / world(移动索敌AI) / progression / offline / shop / meta(统计成就)
  render/             renderer(镜头/视差/合成) / terrain(程序化地形+贴花) / particles / daynight / effects
  ui/                 hud / 六 Tab 面板 / 弹窗(序章/离线/确认/Toast)
  main.js             启动引导
```

**扩展方式**：新增一个区域 = 在 `data/regions.js` 注册一条数据（+ 怪物注册 + 语言包 key + 可选精灵），引擎自动生成地图列表、刷怪、掉落与 UI，零引擎改动。所有内容引用一律走稳定字符串 ID；存档遇到已下线 ID 自动优雅降级（装备折算金币、区域回退）。

**区域顺序**：新档会随机排列前 4 个区域，后 4 个区域保持固定；怪物强度、奖励与推荐等级按本档中的推进位置计算。区域顺序会写入存档，v1/v2 旧档升级后继续使用原来的经典顺序。

## 存档

- localStorage 双槽写入（`firpg_save` + `firpg_save_backup`），主档损坏自动回退备份档。
- 每 15 秒自动保存 + 关键事件（升级/Boss/穿戴/购买等）即时保存 + 页面隐藏/关闭时保存。
- 存档带版本号，预留「版本号 + 迁移函数数组」流水线。
- 导出/导入：Base64 串（末尾附 FNV-1a 校验和，截断/篡改会被拒绝）与 `.json` 文件下载/导入并存；重置需二次确认。
- 检测到存档时间戳在未来（回调系统时间）时离线收益按 0 处理。

## 数值设计说明

**成长方案**：二选一中采用「升级自动成长」——挂机游戏应尽量减少强制打断，玩家的主动决策集中在职业选择、技能加点、装备取舍、商店永久强化四处。升级自动提升全属性、回满 HP 并 +1 技能点。

**职业数值形状**（基础值与复利见 `data/classes.js`）：五职业按「DPS × 有效生命 ≈ 恒定功率预算」设计——战士(HP150/复利1.078)坦而稳、盗贼(SPD12.5/暴击12%)快而脆、法师(ATK17/复利1.075)远程爆发、牧师(治疗强化+吸血)续航、游侠(远程+寻宝)均衡；远程职业以更低生存换取接敌前 1~2 次白嫖攻击。离线估算乘以职业爆发系数（战1.20/贼1.30/法1.35/牧1.15/侠1.25）。

**升级曲线**：`expNeed(L) = 28·L·1.16^(L-1)`（指数）。速度/暴击全职业线性微增。

**伤害公式**：`dmg = atk² / (atk + def)`（平滑减伤，无硬墙），±10% 浮动；暴击默认 150% 可成长。攻击间隔 `1.7·10/(5+spd/2)` 秒，速度既加攻速也间接加 DPS。

**区域怪物匹配**：怪物按区域 tier 指数缩放 `≈2.05^(t-1)`，与「玩家等级复利 × 装备加成（约 35%~55% 战力）」的复合成长率对齐；每区预期停留约 8~10 级，形成「入区偏难 → 毕业碾压」的推图节奏。Boss 为普通怪的 HP×11 / ATK×2.0，首杀奖励魔晶石 `15+10·tier`。

**经济闭环**：金币（产出：击杀/出售/离线；消耗：药水/装备箱）；魔晶石（产出：Boss 首杀/成就/分解传说；消耗：史诗装备箱/永久强化，价格 `10·1.6^已购层数`）。

**离线收益**：`kills = 时长 / (单怪击杀耗时 + 2.5s 位移开销) × 0.8 效率`，收益按当前区域普通怪均值折算，装备掉落上限 30 件（超出折金币方向），无离线时长上限。

**防护设计**：药水低于阈值自动使用（默认 30%，可调，8 秒冷却）；无药水靠自然恢复不中断挂机；死亡零惩罚 + 连败 3 次自动回退；Boss 讨伐失败保留一半进度且血量不足 60% 时 Boss 暂缓登场，避免「登场即团灭」循环。

**大数字**：全局格式化函数按语言分派（zh：万/亿/万亿；en：K/M/B/T），超过 1e16 转科学计数法。
