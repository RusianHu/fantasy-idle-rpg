# 开场体验与环境视觉升级方案（v1.2.0）

> 两条主线：① 重做开场（标题画面 → 序章 → 全屏职业选择，JRPG 仪式感）；
> ② 环境视觉大幅升级（参照歧路旅人 HD-2D 的层次/光影意境，纯 2D 像素实现，
> 全部程序化、可关闭、视口剔除，兼顾低端设备）。允许大规模重构。

## 一、开场体验重做

### 现状问题
- 无标题画面：游戏世界在序章对话背后直接运行，破坏仪式感
- 职业选择是普通列表弹窗：立绘小（40px 静态帧）、无技能预览、无浏览交互

### 新流程（仅新玩家/重置后进入；老玩家秒进游戏不受打扰）
```
标题画面（统一半分辨率 2× 像素网格的半俯视悬崖远眺：极远小比例魔王城/多重雪山/纵深密林/巨兽巢穴/宽阔曲流/低矮石桥/近景营地/四人围火/游侠哨戒/帐篷/旗帜/营灯/补给 + 像素 LOGO）
   └─ 开始冒险 → 序章打字机（标题背景之上）
        └─ 全屏职业选择：
            · 大立绘预览（行走动画自动循环四方向 + 攻击演示，~5× 放大）
            · ←/→ 浏览五职业（可点箭头/滑动）
            · 五维点评 + 特性标签 + 六技能全预览（图标/名称/描述）
            · 底部大按钮确认（二次确认，永久生效）
        └─ 淡出过场 → 进入世界（英雄登场特效 + 「冒险开始」横幅）
```
- v1 迁移档补选职业：直接进全屏职业选择（无标题层）
- 实现：新增 `ui/title.js`（标题场景 canvas + 全屏选职业），复用现有序章打字机；
  移除旧的列表式 classSelect

## 二、环境视觉升级（Octopath 意境 × 像素性能预算）

### 1) 植被重做（新文件 sprites/flora.js，约 20 个高规格精灵）
- 大树规格提升至 20~30px 高、3~4 阶明暗 + 顶部受光高光，**树冠摇曳 2 帧**
 （新增精灵工厂 `sway` 合成操作：顶部 55% 右移 1px）
- 每区域 2~3 种植被变体 + 细节小件（花丛/蕨类/桦树/浆果丛/树桩/碎石/骸骨…）
- 发光体系（数据驱动 `glow: {color, r, flicker}`）：森林荧光菇、矿坑水晶簇、
  墓地烛火、雪山冰晶、熔岩岩浆石、浮空遗迹悬浮水晶（带升降 bob）、魔王城魂灯

### 2) 地表烘焙细节（terrain 大改）
- 草地：大块低透明度色斑（打破均匀感）+ 短笔触草纹；雪地：星点反光；
  石面/泥土：裂纹短线；熔岩：暗色龟裂网；水面：烘焙睡莲 + 岸沿泡沫点
- **草簇系统升级**：数量 ×2.5（按区域 120~160），常态风浪摇曳
 （行波：`sin(t·1.6 + x·0.035)`，扰动时加高频抖动），叶尖高光色
- 花丛：烘焙像素花簇（每区配色）+ 少量 2 帧动态花
- 装饰摆放改为**丛聚算法**（簇心 + 簇内散布），告别均匀撒点

### 3) 光影层（renderer 扩展，全部可关闭 + 视口剔除）
- **道具投影**：大型植被/立柱绘制椭圆软阴影（此前仅实体有影）
- **发光体光晕**：预渲染径向渐变纹理（按色+半径缓存），`lighter` 合成，
  呼吸/烛火抖动两种脉动
- **林间光柱（god rays）**：森林/浮空遗迹白昼绘制 2~3 道斜向半透明光带，
  缓慢漂移，夜晚淡出——歧路旅人的标志性氛围
- **暗角 vignette**：预渲染径向渐变整屏叠加（1 次 drawImage）
- 悬浮水晶 bob 升降、烛火/魂灯光晕高频闪烁

### 4) 性能预算
- 地表全部烘焙进单张画布（一次 drawImage）；树冠摇曳=帧选择零增量
- 草簇 150×3 线段 ≈ 微不足道；光晕 ≤15 个/帧且为预渲染贴图；
  光柱 2~3 个多边形；暗角 1 次 drawImage
- 特效总开关沿用设置项（关闭时：无光晕/光柱/暗角/触发粒子，草簇减半）
- 验收：Playwright 实测森林（最重场景）帧率 ≥ 50fps
