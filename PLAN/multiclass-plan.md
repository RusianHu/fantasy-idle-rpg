# 多职业系统设计方案（v1.1.0）

> 目标：将单一「冒险者」扩展为 DnD 风格的多职业体系——职业之间在**数值成长、战斗机制、
> 技能组、图形、武器**五个维度全面区分；新档开局选择职业（永久，符合 DnD 建卡传统），
> 旧档迁移时补选职业并全额退还技能点。

## 一、职业阵容（DnD 核心四职 + 游侠）

| 职业 | 定位 | 攻击方式 | 数值形状 | 专属机制 |
| --- | --- | --- | --- | --- |
| 战士 Fighter | 近战坦克 | 近战 | 高 HP/DEF，稳定输出 | 战吼增益、战斗回血 |
| 盗贼 Rogue | 近战爆发 | 近战 | 高速高暴击、低防 | 闪避、毒素持续伤害 |
| 法师 Wizard | 远程法术 | **远程**（法弹） | 最高攻击、最脆 | 冷却缩减、奥术护盾 |
| 牧师 Cleric | 近战续航 | 近战 | 坦而奶 | 治疗强化（含药水）、吸血 |
| 游侠 Ranger | 远程物理 | **远程**（弓箭） | 均衡偏敏捷 | 增益鹰眼、寻宝（金币/掉率） |

基准：v1 冒险者（HP120/ATK14/DEF6/SPD10）位于战士与盗贼之间；五职业按
「DPS × 有效生命 ≈ 恒定功率预算」设计，远程职业以更低生存换取接敌前 1~2 次白嫖攻击。

## 二、战斗引擎扩展（新机制，全部数据驱动）

1. **攻击距离**：职业携带 `range`（近战 22 / 远程 72）；远程普攻带**弹道飞行物**
   （法弹/箭矢，命中时结算，目标死亡则消散）。
2. **怪物追击**：被主角锁定的怪物主动走向主角进入近战（修复远程无敌漏洞；
   1v1 基准不变，AOE 波及的旁怪不加入围攻）。
3. **闪避 dodge**：受击方概率 MISS（悬浮字），全局上限 35%。
4. **吸血 lifesteal**：按造成伤害比例回血（受治疗强化加成）。
5. **冷却缩减 cdr**：主动技冷却 ×(1-cdr)，上限 40%。
6. **治疗强化 healPow**：放大一切治疗（药水/技能/自然回复/吸血）。
7. **护盾 shield**：吸收池优先扣除，HUD 显示护盾条。
8. **持续伤害 dot**：中毒等按秒掉血，可致死并正常结算奖励。
9. **临时增益 buff**：限时提升属性（战吼/鹰眼），HUD chip 显示剩余时间。
10. **AOE 中心**：`center: self | target`（远程职业的范围技以目标为中心）。

技能改为**通用 schema**（kind: strike/aoe/heal/buff/shield + 参数），战斗系统提供统一执行器，
新增职业/技能零引擎改动。

## 三、技能组（每职业 3 主动 + 3 被动，解锁节奏与 v1 一致：Lv1/3/5 主动、2/4/6 被动）

- **战士**：重斩(230%+15/级) / 旋风斩(自身AOE 150%) / 战吼(+攻防15%+2/级, 8s)
  ｜坚韧(+6%防+5%命/级) / 武器专精(+5%攻/级) / 战意涌动(战斗中+0.25%生命/秒/级)
- **盗贼**：背刺(190%+13/级，+25%暴击率) / 毒刃(120% + 4秒毒 80%攻+8%/级) / 剑刃乱舞(AOE 130%)
  ｜迅捷(+2.5%速/级) / 致命(+1.2%暴击+5%暴伤/级) / 闪避(+1.5%闪避/级)
- **法师**：火球术(260%+18/级，火弹) / 冰霜新星(目标AOE 160%) / 奥术屏障(护盾 20%+2/级)
  ｜法术精研(+6%攻/级) / 法力涌动(-2%冷却/级) / 魔导护体(+4%命+4%防/级)
- **牧师**：神圣打击(200%+14/级，回复伤害25%) / 治愈祷言(回 22%+2/级，<75%自动) / 神圣新星(AOE 140%+回8%)
  ｜信仰(+5%命+3%防/级) / 圣光祝福(+6%治疗强化/级) / 圣光回响(+1%吸血/级)
- **游侠**：强力射击(220%+15/级，箭矢) / 多重射击(目标AOE 130%) / 鹰眼(+10%攻+10%暴击, 8s)
  ｜精准(+1.2%暴击/级) / 荒野生存(+4%命+2%速/级) / 寻宝直觉(+3%金币+2%掉率/级)

## 四、图形区分（sprites/hero.js 重写为职业精灵工厂）

- 共用腿部/行走帧模板，按职业替换**头部造型 + 服装配色 + 武器**：
  战士=头盔重甲+长剑；盗贼=兜帽皮甲+短匕；法师=尖顶法帽长袍+法杖；
  牧师=白金祭袍头巾+战锤；游侠=羽毛帽绿披风+长弓。
- 每职业：4 方向行走×2帧、侧向攻击（武器差异化）、扎营坐姿、HUD 头像（12×12）。
- 远程攻击弹道：法师紫红法弹（拖尾）、游侠木箭。
- 武器图标 5 款（icon_w_*），背包/装备详情按职业展示。

## 五、装备与武器命名

- 掉落数据不变（通用「武器」槽）；**显示层**按当前职业渲染武器名与图标：
  `铜制长剑 / 铜制短匕 / 铜制法杖 / 铜制战锤 / 铜制长弓`（i18n：item.weapon.<class>）。
- 护甲/饰品全职业通用。

## 六、选职业与存档

- **新档流程**：序章 → 职业选择（5 卡片：立绘、定位、五维点评、特性标签）→ 开始。
- **职业永久**（DnD 传统），换职业 = 重置存档（文档说明）。
- **存档 v1 → v2 迁移**：`classId=null` + 已投入技能点全额退还；载入后弹职业选择
  （老玩家免费补选，等价一次免费洗点）。SAVE_VERSION=2，走既有迁移流水线。

## 七、离线与平衡

- estimateDps 乘以职业爆发系数（战1.20/贼1.30/法1.35/牧1.15/侠1.25），离线收益贴近在线。
- 功率预算校验：各职业「首领击杀耗时 × 生存时长」目标区间一致（±15%），
  上线前用 Playwright 对五职业分别做新手期 90 秒浸泡与 Boss 讨伐实测。
